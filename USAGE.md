# 🎮 GraphWar Bot - Руководство по использованию

## 📋 Что это?

**GraphWar Bot** — это Python-программа, которая автоматически рассчитывает математические функции для точных выстрелов в игре Graphwar.

Бот решает задачу баллистики и предлагает оптимальную формулу для попадания в цель.

---

## 🚀 Быстрый старт

### 1. Установка

```bash
# Клонируем репозиторий
git clone https://github.com/COPacaaa/graphwar-bot.git
cd graphwar-bot

# Никаких зависимостей не нужно! Используем встроенные библиотеки Python
```

### 2. Использование (3 способа)

#### **Способ 1️⃣: Прямой импорт в Python**

```python
from graphwar_bot import GraphwarBot

# Создаём бота
bot = GraphwarBot()

# Боты целится и стреляет!
# Параметры: ваши координаты (x, y) и координаты врага (x, y)
result = bot.aim_and_shoot(
    player_x=0,    # Ваша позиция X
    player_y=0,    # Ваша позиция Y
    enemy_x=50,    # Позиция врага X
    enemy_y=30     # Позиция врага Y
)

# Получаем рекомендуемую формулу
formula = result["recommended"]["formula"]
print(f"Используй эту формулу: {formula}")
```

#### **Способ 2️⃣: Быстрая формула (одна строчка)**

```python
from graphwar_bot import GraphwarBot

bot = GraphwarBot()
formula = bot.get_formula(0, 0, 50, 30)
print(formula)  # y = 0.6000*x + 0.0000
```

#### **Способ 3️⃣: Запуск из командной строки**

```bash
python graphwar_bot.py
```

Выведет примеры расчётов и формулы.

## 📐 Как это работает?

### Тип 1: Линейный выстрел (прямая траектория)

Используется для близких целей, без препятствий.

**Формула:** `y = kx + b`

**Пример:**
- Вы на позиции (0, 0)
- Враг на позиции (10, 5)
- **Результат:** `y = 0.5000*x + 0.0000`

Вводите эту формулу в игру → выстрел летит по прямой в цель ✅

---

### Тип 2: Параболический выстрел (через препятствия)

Используется для обхода препятствий, дальних целей.

**Формула:** `y = a*(x-x₀)² + b*(x-x₀) + c`

**Пример:**
- Вы на позиции (0, 10)
- Враг на позиции (50, 30)
- **Результат:** `y = -0.005432*(x-0)² + 0.8000*(x-0) + 10.0000`

Выстрел летит по дуге, обходит препятствия 🎯

## 💻 API Бота

### Основные методы:

```python
# 1. Полный расчёт со всеми вариантами
bot.aim_and_shoot(player_x, player_y, enemy_x, enemy_y)
# Возвращает: словарь с несколькими вариантами выстрелов

# 2. Быстрая формула
bot.get_formula(player_x, player_y, enemy_x, enemy_y)
# Возвращает: строку с формулой

# 3. История выстрелов
bot.get_history()
# Возвращает: список всех сделанных расчётов
```

## 🎯 Примеры использования

### Пример 1: Близкая цель

```python
bot = GraphwarBot()
formula = bot.get_formula(0, 0, 10, 5)
# Результат: y = 0.5000*x + 0.0000
```

**В игре:**
1. Ввести в поле функции: `y = 0.5*x`
2. Нажать стрелять → **ПОПАДАНИЕ!** 🎉

---

### Пример 2: Дальняя цель

```python
bot = GraphwarBot()
result = bot.aim_and_shoot(0, 20, 100, 50)

# Смотрим все варианты
for shot in result["shots"]:
    print(f"{shot['type']}: {shot['formula']}")
```

Выбираем лучший вариант из предложенных.

---

### Пример 3: Много выстрелов подряд

```python
bot = GraphwarBot()

# Враги приближаются!
enemies = [
    (10, 5),
    (20, 15),
    (50, 30),
    (100, 50)
]

for enemy_x, enemy_y in enemies:
    formula = bot.get_formula(0, 0, enemy_x, enemy_y)
    print(f"Враг на ({enemy_x}, {enemy_y}): {formula}")
    # Используете формулу в игре и стреляете!
```

## ⚙️ Параметры и настройки

### Гравитация

По умолчанию используется земная гравитация (9.8 м/с²). Можно изменить:

```python
from graphwar_bot import TrajectoryCalculator

calc = TrajectoryCalculator()
calc.gravity = 5.0  # Для луны 😄
```

### Угол выстрела

Бот автоматически подбирает углы 45° и 30°. Можно указать свой:

```python
from graphwar_bot import TrajectoryCalculator, Position

calc = TrajectoryCalculator()
formula = calc.calculate_parabolic_shot(
    player=Position(0, 0),
    enemy=Position(50, 30),
    angle_degrees=60  # Выстрел под углом 60°
)
```

## 🎮 Как использовать в игре Graphwar?

1. **Запустите программу:**
   ```bash
   python graphwar_bot.py
   ```

2. **Откройте игру на https://graphwar.com/**

3. **Введите свои координаты и координаты врага в программу**

4. **Получите формулу из бота**

5. **Скопируйте формулу в поле ввода функции в игре**

6. **Нажмите "Выстрелить"** → **ПОПАДАНИЕ!** 🎯

---

## 💡 Советы

- 📌 **Для близких целей** используйте линейный выстрел (быстрее)
- 🏔️ **Если есть препятствия** используйте параболический выстрел
- 🎯 **Точность** зависит от правильности введённых координат
- ⏱️ **Скорость** — бот считает за миллисекунды!

---

## 🐛 Если что-то не работает

1. Проверьте версию Python: `python --version` (нужна 3.6+)
2. Проверьте координаты (X, Y должны быть числа)
3. Убедитесь, что враг не прямо над вами (dx не равен 0)
4. Откройте issue на GitHub: https://github.com/COPacaaa/graphwar-bot/issues
